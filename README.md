# Система распознавания жестов (1000+ классов)

Модель для real-time классификации русского жестового языка (РЖЯ), включая дактильный алфавит и динамические жесты. Проект реализует иерархический подход к классификации с использованием трех специализированных нейронных сетей. В качестве обучающих данных использовался датасет [Slovo](https://github.com/hukenovs/slovo/).

## Основные особенности

- **Разделение ответственности (Divide and Conquer)**: Вместо одной тяжелой модели используется каскад из трех оптимизированных сетей:
  - **Alphabet Model**: Специализированная сеть для статичных жестов букв алфавита (33 класса).
  - **Complex Model**: Модель для 200 "трудных" жестов.
  - **General Model**: Основная модель для 800+ динамических жестов.
- **Инвариантность к пространству и масштабу**
- **Эффективный инференс**: Стратегия **Maximum Confidence** позволяет выбирать наиболее вероятное предсказание среди нескольких моделей без использования тяжелого диспетчера.

## Архитектура системы

Система обрабатывает буфер из 40/60 кадров ключевых точек MediaPipe (165 признаков на кадр).

### Препроцессинг данных
Внутри модели реализованы кастомные слои для обработки "на лету":
- **Centralization**: Координаты централизируются относительно плеч.
- **Normalization**: Масштабирование координат на основе ширины плеч.

### Структура нейронных сетей
Все модели используют гибридную архитектуру:
- **Bidirectional LSTM**: слои для моделирования временных рядов.
- **Statistical Aggregation**: Комбинация `GlobalAveragePooling1D`, `GlobalMaxPooling1D` и `reduce_std` для захвата динамики движения.
- **Classification Head**: Глубокие полносвязные слои с `BatchNormalization` и `Dropout` для борьбы с переобучением.

## Технологический стек

- **TensorFlow / Keras**: Ядро системы и обучение моделей.
- **MediaPipe**: Извлечение Landmarks в реальном времени.
- **Python**: Скрипты обработки данных и инференса.
